# 符号计算与代数系统

东京大学符号计算与代数系统课程项目。

## 项目简介

用Python实现一个能处理符号多项式运算和自动求导的程序。不依赖第三方库（如sympy），重在理解符号计算原理。

## 核心功能

- **词法分析**：将输入字符串转换为Token流
- **递归下降解析器**：处理括号嵌套和运算符优先级
- **多项式化简**：合并同类项、消除冗余
- **自动求导**：符号求导，支持链式法则

## 文件结构

| 文件 | 功能 |
|------|------|
| `lexer.py` | 词法分析器 |
| `expr.py` | AST节点类 |
| `parser.py` | 递归下降解析器 |
| `simplify.py` | 多项式化简 |
| `derivative.py` | 自动求导 |
| `main.py` | REPL交互入口 |

## 使用方法

```bash
python main.py
```

### 命令示例

```
# 直接计算
> x^2 + 2*x
x^2 + 2*x

# 求导
> d/dx(x^2 + 2*x)
2*x + 2

# 化简
> simplify(2*x + 4 - x + 2)
x + 6

# 退出
> quit
```

## 求导规则

| 规则 | 说明 |
|------|------|
| d/dx(c) = 0 | 常数导数为0 |
| d/dx(x) = 1 | 变量导数为1 |
| d/dx(f+g) = f' + g' | 加法规则 |
| d/dx(f*g) = f'*g + f*g' | 乘法规则 |
| d/dx(f^n) = n*f^(n-1)*f' | 链式法则 |
