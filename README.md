## 1. Symbolic Computation System 
### From University of Tokyo
Language:Python

Background:编写一个能进行多项式运算和自动求导的程序 

Challenge:

1.非数值运算：程序不是计算 $2+3=5$，而是处理符号，比如输入 x^2 + 2x，程序要能输出导数 2x + 2。

2.递归解析：你需要编写一个递归下降解析器来处理括号嵌套和运算优先级。

Project Branch: project-Utokyo-Symbolic-Computation-System

Project Website: https://github.com/markblogforpublic/Famous_Universities-_Projects/tree/project-Utokyo-Symbolic-Computation-System
